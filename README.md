Community Watcher
A Windows desktop application for residents to report municipal service delivery issues.

Prerequisites

Windows 10 or 11
.NET Desktop Runtime 6.0 or later
Installation
Download and extract CommunityWatcher.zip from the from GitHub download page.
Keep all extracted files in the same folder.


How to Run

Double-click CommunityWatcher.exe.
From the main menu, click Report Issues.
Fill in the Category, Location, and Description fields.
Optionally attach a file, then click Report Issue to submit.
Built With
C# / .NET / Windows Forms
